About

How should an agent learn to work with this particular user?

USIL studies how AI agents learn from user-specific evidence to adapt how they communicate, elicit input, respond to feedback, collaborate, and exercise autonomy over time.

As AI systems become persistent agents that plan, use tools, and act on users’ behalf, personalization must extend beyond preferred outputs. Agents increasingly need to learn how particular users want them to coordinate, seek input, respond to correction, and exercise autonomy.

USIL brings together personalized agents, user modeling, memory, preference learning, continual adaptation, human–AI interaction, and interactive agents around a common downstream learning target: the user-specific interaction policy.

Why now? The relevant pieces are advancing rapidly across multiple communities, but are rarely studied together as one end-to-end learning problem: how feedback from an individual user should be retained, generalized, translated into interaction decisions, and evaluated over time.
This website describes a proposed ICLR 2027 workshop. Program details are tentative and subject to workshop acceptance and the official ICLR schedule.
Research agenda

Four questions at the center of USIL

P1

Learning from sparse and evolving user evidence

How should agents learn from demonstrations, edits, corrections, approvals, interruptions, takeovers, and natural-language feedback without overreacting to isolated signals?

P2

Representing and generalizing interaction preferences

What should an agent represent about a user, and what should transfer across tasks, tools, domains, and agent backends?

P3

When should an agent infer, ask, act, or defer?

How should user-specific preferences for oversight and autonomy change decisions about clarification, confirmation, delegation, and control?

P4

Evaluation and benchmarks

How should we evaluate whether an agent behaved appropriately for a particular user rather than only for an aggregate user?

Topics include

  • User-specific interaction and behavioral policies
  • User modeling, preferences, goals, expertise, and interaction tendencies
  • Learning from corrections, edits, demonstrations, approvals, and takeovers
  • Active elicitation and when to ask, infer, act, defer, or return control
  • Few-shot and continual adaptation to individual users
  • Memory and retrieval for behavioral adaptation
  • Personalized autonomy, delegation, confirmation, and intervention
  • Transfer across tasks, tools, agents, domains, and embodiments
  • Preference or reward learning for interaction adaptation
  • Benchmarks and evaluation for user-specific interaction
  • Privacy, safety, manipulation, user agency, and limits on personalization
  • Conceptual foundations, problem formulations, and open research questions
